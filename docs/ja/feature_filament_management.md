# フィラメントスプール管理と在庫追跡

ここでは、3dpmon のフィラメント管理機能を活用してスプール残量を把握し、在庫を管理する方法を紹介します。v2.2.1045 RC では、通常の手動スプール台帳に加えて、K2/CFS や K1C/CFS-C から取得した機器観測フィラメントを read-only 情報として表示できます。

## スプール登録
- フィラメント管理パネルの **追加** ボタンからスプール情報を登録します。
- スプール名、総巻き長さ、現在の残り長さに加え、メーカー名や材料名も設定可能です。
- 登録されたスプールには **#NNN** 形式のシリアル番号が自動付与され、一覧での識別が容易になります。
- 登録後はパネル上に 3D スプールプレビューが表示され、消費量が自動的に更新されます。
- 未確認の推定 candidate がある場合、通常のフィラメント管理画面にも **確定残量**、**推定残量**、**未確認推定** が分離表示されます。

## K2/CFS・K1C/CFS-C の機器観測フィラメント

K2/CFS や K1C/CFS-C では、プリンタや材料供給装置が報告する外部スプール、CFS unit、CFS slot の状態を通常スプールとは別に表示します。

- 外部スプールと CFS slot は混ぜずに別枠で表示します。
- CFS/CFS-C は0台から4台まで、外部スプールを含めて最大17巻構成を表示できます。
- slot の色、材料名、残量、装填状態、機器選択状態、`T1A` などの割当観測を確認できます。
- CFS情報が stale の場合は、現在値ではなく「最終観測」として表示します。
- 残量の報告値が異常な場合は、0%へ丸めず `残量 不明` と表示します。

これらの情報は `materialSourceObservations` に read-only 証跡として保存されます。通常の `hostSpoolMap`、装着履歴、使用履歴、在庫数へは自動反映されません。Creality純正RFIDフィラメント以外では残量が報告されない場合があるため、その場合は3DPmon側の通常スプール台帳で残量を管理してください。

> [!IMPORTANT]
> v2.2.1045 RC では、CFS/CFS-C の standalone load / unload / feed / retract / slot select は有効ではありません。表示は監視用であり、フィラメント操作はプリンタ本体またはcertification済みの後続版で行います。

## グローバルデータと Per-host データの区別
フィラメント関連データは、グローバル、per-host、機器観測の3種類に分離管理されます。

| データ種別 | 管理範囲 | 説明 |
|---|---|---|
| スプールプリセット | グローバル | 材料・メーカー等のプリセット定義。全プリンタ共通 |
| スプール在庫 | グローバル | スプールリスト・在庫数。どのプリンタからでも同じ在庫を参照 |
| 装着スプール | **Per-host** | `hostSpoolMap` で各プリンタに現在装着中のスプールを個別管理 |
| フィラメント消費量 | **Per-host** | 消費履歴はプリンタごとに記録。データの混在なし |
| 機器観測フィラメント | **Read-only observation** | `materialSourceObservations` で外部スプール/CFS slotの最終観測を保存。台帳authorityではない |

## Per-host スプール装着
- **`hostSpoolMap`** により、各プリンタにどのスプールが装着されているかを個別に管理します。
- プリンタ A に PLA スプール、プリンタ B に ABS スプールを装着するなど、独立した運用が可能です。
- フィラメント交換操作（`setCurrentSpoolId` / `useFilament` / `reserveFilament` / `finalizeFilamentUsage`）はすべて hostname 引数付きで呼び出され、正しいプリンタに紐付きます。

## 在庫管理
- スプール交換時に在庫数が自動で減算されるため、手動入力の手間が省けます。
- 在庫が不足すると警告が表示され、購入リンクを開くこともできます。

## Per-host フィラメント消費追跡
- 消費履歴はプリンタごとに個別記録されます。
- 集計レポート機能を使うと、日別や月別の消費量をグラフで確認できます。
- どのプリンタでどれだけのフィラメントを消費したかを正確に把握できます。
- 表示や予測には推定残量を参照できますが、在庫消費、runout 確定、廃棄などの不可逆操作は確定残量だけを基準にします。

## パネルシステム
フィラメント管理は GridStack パネルとして表示されます。3D スプールプレビューや消費量グラフをドラッグ・リサイズで自由に配置できます。

## 活用のヒント
- `dashboard_spool.js` を改造することで、独自のスプールデータベースを構築できます。
- 集計レポート機能を使うと、プリンタ別・日別・月別の消費量をグラフで確認できます。
